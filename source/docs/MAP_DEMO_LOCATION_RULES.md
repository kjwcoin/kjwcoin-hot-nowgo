# 지도 예시 위치 규칙

기본값: HOT·SWEET·RICH의 첫 지도와 `내 위치` 버튼은 각 방문자의 GPS 좌표를 중심으로 카카오맵 배율 5를 사용한다. 확인된 위치에서 15km 안의 실제 메뉴만 조회한다. 위치 권한이 없으면 내 위치인 척 임의 좌표나 청라 예시를 표시하지 않고 주소 검색으로 위치를 지정하게 한다.

HOT·SWEET·RICH의 예시 매장 좌표를 만들거나 이동할 때 적용한다.

1. 거리와 각도로 계산한 좌표를 지도에 바로 표시하지 않는다. 해당 좌표의 카카오 지번주소와 숫자로 된 지번이 확인된 경우에만 사용한다. 바다와 주소 조회 실패 지점은 버린다. 해변이나 섬에서 실제 해역이 카카오 바탕 지도에 보일 수는 있지만 바다 위 가매장 마커를 허용하지 않는다.
2. 위치 권한을 받기 전에는 내 위치 주변 예시를 표시하지 않는다. 기존 가매장 3개는 방문자마다 확인된 위치의 15km 안에서 다시 배치한다. 확인된 육지 지점이 3곳보다 적으면 확인된 지점만 표시한다. 바다 좌표로 부족한 수를 채우지 않는다.
3. 예시 매장은 반드시 가상 정보임을 표시한다. 실제 등록 매장과 섞어 실제 영업 중이라고 안내하거나 영업 상태의 근거로 사용하지 않는다. 운영 사용자에게 실제 매장만 보여주는 별도 정책을 적용할 때는 예시 데이터를 결과에서 완전히 분리한다.
4. 좌표 생성·필터를 수정하면 주소 미확인 좌표 제외, 검색 반경 경계, 실제 매장 좌표 보존을 검사한다. 해안 도시의 위치를 넣고 지도 마커가 바다에 없는지 화면에서도 확인한다.
5. 제보 주소를 수정하면 이전에 선택한 지도 좌표를 지운다. 주소 검색 또는 지도 클릭으로 새 위치를 확인한 뒤 주소와 좌표를 함께 제보에 전달한다.
