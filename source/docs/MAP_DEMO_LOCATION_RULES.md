# 지도 기본값

- HOT·RICH·SWEET 지도는 각 방문자의 GPS 좌표를 중심으로 동네 배율 5를 사용한다. 내 위치 버튼을 다시 눌러도 배율 5다. 위치가 없으면 청라 등 임의의 지역을 사용자 위치로 안내하지 않고 주소 입력을 제공한다.
- 반경은 15km다. 서버 조회와 브라우저 목록 모두 15km 안의 실제 메뉴만 허용한다.
- 개발용 가매장 3개는 GPS 또는 주소로 지정한 위치 주변의 카카오 지번주소와 숫자로 된 지번을 확인한 좌표에만 배치한다. 주소가 없는 바다 좌표를 채우지 않는다. 육지 좌표가 부족할 때는 3개보다 적게 보여준다.
- 가매장은 실제 영업 매장과 구별되게 표시하고 영업 여부의 근거로 쓰지 않는다. 해안 방문자의 지도 바탕에 실제 바다가 들어갈 수는 있으나 바다 위 가매장 마커는 허용하지 않는다.
