# HOT · SWEET · RICH 점주 운영 패널

점주 로그인 후 `내 매장관리`는 매장 운영 패널을 표시한다. 일반 회원은 기존 모험 기록을 유지한다. 회원이 선택한 계정 유형이나 수정 가능한 사용자 metadata 대신, 서버에서 확인한 `owners` 회원 여부로 화면을 구분한다.

## 운영 상태

- 영업중 / 영업마감 / 재료소진 마감 / 임시휴무 / 브레이크 타임 / 폐업
- 혼잡함 / 여유있음, 같은 혼잡도 버튼을 다시 누르면 해제
- 오늘만: 다음 04:00 KST까지. 직접 해제: 직접 변경 가능하지만 공개 정보 유효기간은 최대 24시간.
- 폐업 설정 전 별도 확인. 제보 상태로 되돌리기는 점주 override를 해제한다.
- 영업시간은 NOWGO의 등록 정보를 표시하고 기존 점주 대시보드에서 편집한다.
- 영업 시작 전 매일 확인 안내, 오늘 확인 여부와 마지막 갱신 시각 표시.

`/api/owner/operations`는 사용자 JWT를 검증하고 데이터베이스 RPC를 호출한다. 변경 RPC는 `auth.uid()`로만 점주를 결정하고 활성 점주 여부·실제 소유권·구독 권한·신뢰 정지 여부를 검사한다. 실제 저장은 NOWGO의 `replace_owner_status_v2`를 사용하며 원래 상태 감사 기록과 멱등 키를 유지한다.

지도는 같은 `owner_overrides`에서 실제 등록 매장의 신선한 상태만 읽는다. 같은 브라우저에서는 저장 이벤트로 즉시 다시 조회하고, 다른 접속에서는 15초 주기로 갱신한다. 폐업 버튼은 데이터 삭제나 매장 보관 처리를 실행하지 않는다.

## 신뢰와 패널티

첨부한 NOWGO 화면의 매장 그림·동적 간판·레벨 휘장을 사용한다. 실제 `stores.owner_penalty_points`와 `owner_trust_incidents`만 표시한다. 허위 예시 점수를 운영 화면에 넣지 않는다.

기존 트리거를 재사용한다. 서로 다른 로그인 고객 3명 이상이 점주 정보보다 새로운 일치 제보로 영업·등록 메뉴 품절 정보를 정정하면 건당 신뢰 5점 차감 및 패널티 5점 누적. 같은 정정은 중복 계산하지 않는다. 30점이면 공개 조회와 상태 변경을 차단한다. 미접속 자체에 대한 별도 감점·금전 패널티는 만들지 않는다.

## 가격 및 배포 전제

- 가입 후 지도 이용은 무료.
- 지도 점주 제보 상품: 월 1,900원, VAT 포함, 무료 체험 없이 명시적인 구독 신청 시 첫 결제.
- 확인된 기존 StepPay 상품: `product_imaqLBf8q`, 플랜 `price_NZ6mkW2nM`. 상품을 새로 생성하지 않았다.
- SPACE SaaS: 가입일 기준 3개월 무료 후 월 9,900원, VAT 포함. 별도 상품이며 지도 상품의 무료 체험으로 간주하지 않는다.
- 운영 상태 권한은 서버에서 검증된 월 1,900원 지도 유료 구독으로만 판단한다. SPACE의 무료 기간·유료 구독은 별도 상품이며 지도 제보 권한을 부여하지 않는다.

`ng_map_subscription_access`는 유료 지도 계약에 대한 서버 전용 연결 지점이다. 이번 점주 패널 작업은 실제 StepPay 결제를 실행하거나 가짜 결제 완료 기록을 만들지 않았다. 결제 API·웹훅 연동에서 실제 결제와 계약을 확인한 뒤에만 이 테이블에 반영해야 한다. 현재 StepPay PG는 테스트 모드로 확인되어 실결제 검증이 완료되지 않았다.

## 검증

- Next.js production build와 TypeScript 검사.
- 전체 Node 테스트 및 영업 상태 API의 로그인·출처·명령 검증.
- 개발 DB에서 `supabase/tests/map_owner_operations.sql`: 상태 6종, 동일 원장 지도 조회, 혼잡도, 중복 요청, 타 점주 차단, 구독 권한, 만료, 30점 정지. 모든 테스트 자료는 transaction rollback으로 제거.
- 로컬 브라우저 검증은 실행 환경의 브라우저 daemon이 시작되지 않아 완료하지 못했다.

사용자가 운영 DB 변경과 기존 NOWGO 매장 이미지의 HOT·SWEET·RICH 공개 사용을 명시적으로 승인했다. 지도 상품에 SPACE 무료 기간이 섞이지 않도록 권한 검사를 유료 지도 구독으로 한정했다. 운영 RPC 적용을 확인한 뒤 공통 main에서 세 서비스를 배포한다.
