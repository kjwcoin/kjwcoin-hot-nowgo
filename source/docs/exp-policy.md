# NOWGO EXP·성장 정책

기준: 2026-10-14. 최신 사용자 결정과 기존 서버 기록을 통합한다. 기존 누적 EXP를 초기화하지 않는다.

- 정상 메뉴·맵기·맛 제보: 저장·공개 완료 시 50 EXP. 같은 매장·같은 메뉴의 재수정·재전송은 중복 지급하지 않는다.
- 영업상태 신고(영업중·영업마감·정기휴무·임시휴무·재료소진 마감·폐업): 서로 다른 고객 3명 이상이 일치한 뒤 50 EXP. 같은 매장 상태 보상은 한국 시간 기준 하루 1회. 잠정 상태는 즉시 고객 제보로 표시한다.
- 결제와 GPS 일치 방문 인증: 40 EXP. 해당 인증 방문의 사진: 20 EXP.
- 오늘의 제보·방문·상태 퀘스트: 각 10 EXP, 행성별 하루 1회.
- 하루 총 100 EXP, 종류별 보상 최대 3회. 한도 초과 제보도 접수하되 보상은 추가하지 않는다.
- 대기·반려·중복은 0 EXP. 허위 제보 확정으로 취소된 보상만 회수한다.
- 같은 계정의 웹·모바일·앱이 서버 원장을 공유한다. HOT·SWEET·RICH 성장은 행성별로 관리한다.
- 고객 EXP와 점주의 신뢰 점수는 분리한다. 스탬프는 실제 방문 인증에 연결하며 맛 제보만으로 생성하지 않는다.

| 등급 | 레벨 | 누적 EXP |
|---|---:|---:|
| 탐험가 | 1 | 0 |
| 기사 | 3 | 150 |
| 성주 | 5 | 500 |
| 백작 | 10 | 3,000 |
| 공작 | 20 | 15,500 |
| 왕 | 30 | 38,000 |

초반 레벨 2는 50 EXP. 이후 필요량은 점차 증가한다. 모든 레벨 기준은 `lib/activity/model.ts`의 단일 배열로 관리한다. EXP·레벨 안내 페이지는 같은 배열을 직접 읽는다.

## 기존 대화의 수치 통합

10/5와 10/6 초안에는 여러 EXP·등급 기준이 있었다. 10/9의 기사180·성주500와 행성별 성장, 오늘의 퀘스트10, 중복 방지 요청을 기존 구현과 대조했다. 10/13 정상 제보50 요청을 우선 적용하고, 10/14 초반 쉽게·후반 어렵게 요청으로 기사150·왕38,000 등 새로운 완만한 증가 곡선을 적용한다. 이전 공개 제보30은 신규 정상 제보50으로 대체한다. 현재 구현 방문40·사진20은 유지한다.

## 점주

점주는 통합회원 월8,000원 가입 화면에서 대표메뉴를 바꿀 수 있다. 기존 고객 제보는 당시 메뉴명에 남고 새로운 대표메뉴로 자동 이전되지 않는다. 전용 웹앱 주소에서 영업현황을 갱신한다. SPACE와 동일하게 신뢰30 시작, 서로 다른 고객3명 이상 일치해 영업·품절 정보가 정정되면 건당5 차감, 0점 공개 노출 중지·데이터 보존. SPACE의 현재 운영 정책에는 하루 미등록만으로 자동 감점하는 규칙이 없다.
