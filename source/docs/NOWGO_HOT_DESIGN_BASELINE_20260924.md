# NOWGO HOT 설계 기준 · 통합회원 개정본

작성일: 2026-09-24
승인 근거: 대표의 본 대화 지시 — 설계 저장, 실제 코드 반영·배포, 빨간 NOWGO 로고, 맛잘알 프로모션, 통합회원 가입.
문서 역할: 디자인·개발·운영이 함께 참조하는 기준. 아래 ‘실제 반영 범위’와 목표 설계를 구분한다.

## 1. 목표와 서비스 역할

가게엔 단골을. 손님에겐 여유를.
메뉴를 발견한 손님이 NOWGO에서 실제 매장 상태를 확인하고 방문한 뒤 리뷰와 단골 관계로 이어지게 한다. 매출이나 할인 지급을 보장하지 않는다.

| 영역 | 역할 | 기록의 원천 |
|---|---|---|
| HOT 전체 지도 | 메뉴·맵기·맛·예산으로 음식 발견 | 메뉴 제보 및 NOWGO 매장 연결 |
| 프로모션 8단 | 참여 이유 설명과 제보 유도 | 캠페인 기획 |
| NOWGO 매장 미니홈피 | 영업·품절 확인, 리뷰, 단골 등록 | NOWGO 공식 매장 ID |
| 점주 화면 | 소유권 확인 후 상태와 단골 관리 | NOWGO 소유권 및 점주 권한 |
| NOWGO 통합회원 | 가입·로그인·개인정보·수신 동의 | 단일 회원 ID |

공통 여정: 메뉴 발견 → NOWGO 상태 확인 → 방문 → 미니홈피 리뷰·단골 등록 → 다음 메뉴 발견.
카카오맵은 지도 배경과 좌표 확인만 제공한다. 카카오 매장 검색 결과를 영업·품절 확인의 근거로 쓰지 않는다.

## 2. 최종 브랜드와 캠페인

상단에는 첨부한 NOWGO 이미지 로고를 빨간색으로 바꾼 이미지 하나만 사용한다. HOT 글자, by, 로고 밑 슬로건은 넣지 않는다. 프로모션·지도·매장 연결 화면에 같은 컴포넌트를 사용한다.

프로모션 중심 컨셉: **맛잘알이 제보하는 핫한 맛부심**.
맛부심은 과도한 매운맛 도전이나 긍정 리뷰 경쟁이 아니라, 내가 아는 맛을 다른 사람이 믿고 찾게 하는 정확한 기여로 표현한다. 특정 성향의 평가를 보상하지 않는다.

| 단 | 화면의 역할 | 핵심 문구·행동 |
|---|---|---|
| 1 | 정체성과 메뉴 지도 진입 | 맛잘알이 제보하는 / 핫한 맛부심. 내가 아는 그 한 접시. 누군가의 오늘 메뉴가 되도록. |
| 2 | 음식 탐색 | 지금 당기는 한 접시. 맛·맵기·한 끼 예산으로 좁히기 |
| 3 | 취향의 차이 | 잘 먹는 맵기보다 좋아하는 맵기. 다섯 단계의 익숙한 맵기 |
| 4 | 출발 전 확인 | 맛있게 가고 헛걸음은 줄이고. 영업과 메뉴 품절 각각 확인 |
| 5 | 제보 | 이 메뉴는 내가 좀 알지. 메뉴·가격·사진·확인 날짜 |
| 6 | 점주 전환 | 한 번 온 손님이 다시 오는 손님으로. 가입과 소유권 확인 |
| 7 | 기여와 성장 | 맛잘알의 기준은 다음 사람이 믿는 정보. 확인된 기여로 성장 |
| 8 | 반복 이용 | 가게엔 단골을. 손님에겐 여유를. 메뉴 지도로 재진입 |

8단 수를 유지한다. 음식 사진과 실제 필터·지도·제보 동작을 중심으로 구성하며 가짜 방문자 수나 후기 수는 표시하지 않는다.

## 3. 지도·상세 화면

화면을 지도 중심으로 채운다. 상단에는 빨간 NOWGO 로고, 검색창, 오른쪽 통합 로그인. 다음 줄에는 맵기 단계·맛 분류·메뉴 종류·한 끼 예산. 필터는 AND 조건이다.

- 맵기: 순한맛 / 약간 매운맛 / 보통 매운맛 / 매운맛 / 아주 매운맛.
- 맛 분류: 얼큰한 / 칼칼한 / 달콤매콤한 / 알싸한.
- 예산: 전체 / 1만 원 이하 / 1만 5천 원 이하 / 2만 원 이하.
- 검색 예: 닭발, 떡볶이, 칼국수. 목록과 지도에 같은 결과 반영.
- 오른쪽 아래 ‘제보 및 등록’은 프로모션의 제보 폼으로 이동.
- 상세에는 가격 출처·확인일·매장 영업·해당 메뉴 품절·마지막 공식 확인시각 표시.
- 상세 하단 ‘나우고 점주 가입하기’는 확인된 NOWGO 점주 진입 경로로 이동. 가입 완료나 Free 생성 완료로 표시하지 않는다.
- 가매장: ‘실제로 영업하지 않는 개발용 가매장입니다. 현실에 없는 매장입니다.’ 목록·앵커·상세에서 구분. 실제 리뷰·소유권 신청 대상으로 쓰지 않는다.

## 4. 통합회원 원칙

HOT 전용 회원가입은 폐기한다. 모든 테마가 NOWGO에서 발급한 동일한 canonical member ID를 사용한다. 고객도 점주도 하나의 회원이고 점주 권한은 승인된 매장별 추가 권한이다.

통합가입 입력은 닉네임·휴대폰 번호·비밀번호. 비밀번호 원문을 저장하지 않고 중앙 인증 서비스에서만 처리한다. 휴대폰 입력과 번호 소유 확인은 별개다. 전화번호만 같다고 기존 단골·회원·점주를 자동 병합하지 않는다.

가입 시 필수 약관·개인정보 동의와 선택 문자·카카오 동의를 각각 기록한다. 가입 자체는 광고 수신 동의가 아니다. 매장별 광고 근거는 플랫폼 이벤트 동의와 별도로 확인한다. 실제 발송 시 최신 동의와 번호 인증, 매장 관계, 수신 거부 상태를 다시 검사한다.

HOT은 통합가입 화면으로 이동하고 인증 후 HOT으로 돌아와 같은 회원을 인식한다. 브라우저 쿼리나 닉네임을 회원 인증으로 신뢰하지 않는다. 기존 HOT 검수 계정·비밀번호·제보 이력은 임의 삭제·병합하지 않고 명시적 이관 검증 대상으로 보존한다.

## 5. 제보와 자동 등재

열람과 폼 작성은 비회원도 가능하다. 제출은 서버가 확인한 NOWGO 통합회원만 허용한다. 회원 여부와 매장 소유권은 따로 판단한다.

정상 조건: 대한민국 주소와 좌표, 메뉴·상호·가격·맵기·맛 분류, 실제 확인 날짜, 사진 형식·용량, 사진 권리와 정확성 동의, 중복 및 시간당 제출 제한. 정상 신규 제보는 사람의 사전 승인 없이 ‘고객 제보 · 점주 미확인’으로 등재한다.

주소·필수값 오류는 반려하고 입력을 유지한다. 중복은 재등록하지 않는다. 90일이 지난 근거 또는 설명에 연락처 노출이 감지된 제보는 `held_for_review`로 비공개 접수한다. 자동 검사는 사진 내용이나 사실·권리의 완전한 검증이 아니다. 분쟁·신고·의심 제보를 처리하는 운영 절차가 별도로 필요하다.

‘점주·요리사’ 선택만으로 공식 점주가 되지 않는다. 점주의 공식 영업·품절 변경은 NOWGO의 소유권 승인 이후에만 허용한다.

## 6. 상태의 신뢰 기준

매장 영업과 메뉴 품절은 독립된 상태다. 영업 중이어도 해당 메뉴가 품절일 수 있고, 품절 목록에 없다고 주문 가능으로 추정하지 않는다.

공식 상태 응답에는 매장 ID, 원천, 점주 소유권 확인, 확인시각, 만료시각이 있어야 한다. 메뉴 응답에는 정확한 메뉴 ID와 별도 확인·만료시각이 있어야 한다. 만료·미래시각·점주 미확인·연결 장애·잘못된 ID는 ‘확인 필요’로 표시한다. HOT은 중앙 상태를 임의 연장하지 않으며 최대 24시간을 넘는 상태 증거는 채택하지 않는다. 중앙에서 더 짧게 만료시키면 그 시각을 따른다.

현재 상태는 도착 시각의 이용 가능 보증이 아니다. 도착시점 예측은 별도 근거가 확보된 뒤 구분해서 제공한다.

## 7. 리뷰·레벨·단골

리뷰 작성·조회·수정·삭제와 리뷰 사진은 NOWGO 미니홈피에만 쌓인다. HOT은 리뷰 본문과 사진을 중복 저장하지 않는다. 미연결 매장은 ‘매장 연결 준비 중’. 가매장은 리뷰를 받지 않는다.

첫 가입·레벨 1부터 리뷰 작성 가능. 글 수, 좋아요, 긍정 평가, 링크 클릭으로 레벨을 올리지 않는다. 중앙에서 검증한 기여 점수만 반영한다. 삭제·허위 판정·기여 철회 시 중앙에서 점수를 취소한다.

| 레벨 | 제안 기준 | 제공 범위 |
|---|---:|---|
| 첫 한 접시 | 0점 | 메뉴 저장·제보·미니홈피 리뷰 |
| 동네 발견자 | 30점 | 기여자 표시 |
| 한 끼 길잡이 | 100점 | 체험 모집 우선 신청, 실제 파트너 확보 후 |
| 동네 맛길지기 | 300점 | 정정 검토 우선 접수, 운영 연결 후 |

체험·할인·시식은 점주가 실제 제공하기로 한 것만 표시한다. 레벨이 높아도 공식 영업·품절 편집 권한은 없다. 단골 관계는 고객의 별도 등록 행위로 생성하며 통합가입만으로 모든 매장의 단골이 되지 않는다.

## 8. 구현한 HOT 연결 계약

이 항목은 HOT 측 구현 계약이며 NOWGO 중앙 서버에 이미 존재하는 API라고 주장하지 않는다.

### 인증

환경변수 `NOWGO_AUTH_AUTHORIZE_URL`, `NOWGO_AUTH_TOKEN_URL`, `NOWGO_AUTH_USERINFO_URL`은 확인된 중앙 URL만 설정한다. HTTPS nowgo.space/www.nowgo.space만 허용한다. 클라이언트 ID·서버 비밀키·정확한 callback URL·세션 암호화키도 필요하다.

HOT `/api/auth/start`는 state와 PKCE S256을 생성한다. `/api/auth/callback`은 state 쿠키와 서버의 10분 만료 일회용 요청을 확인하고 code를 서버에서 교환한다. code 재사용은 거절한다. access token은 AES-GCM으로 암호화해 저장하며 브라우저에는 HOT 전용 HttpOnly 세션 쿠키만 전달한다. 세션 수명은 중앙 토큰 만료 또는 1시간 중 짧은 값. 매 인증 요청 시 중앙 프로필을 재확인하며 철회·장애 시 권한을 주지 않는다.

중앙 userinfo 응답 계약:
`sub`(변경되지 않는 회원 ID), `status: active`, `nickname`, 선택 `phone_masked`, `phone_verified`, `verified_contribution_points`.
원문 번호와 비밀번호는 HOT에 전달하지 않는다. HOT 내부 활동 키는 `nowgo:{sub}`. 기존 HOT ID와 충돌하지 않으며 전화번호 자동 병합을 하지 않는다.

### 상태

`NOWGO_STATUS_API_URL`에 `hot_place_id`와 `hot_menu_id`를 서버 요청한다. 선택 서버 토큰은 `NOWGO_STATUS_API_TOKEN`.
응답: `hot_place_id`, `place_id`, `minihome_url`, `owner_verified`, `source`, `status`, `observed_at`, `expires_at`, `menu: {hot_menu_id, status, observed_at, expires_at}`.
미설정·오류 응답은 확인 필요. 현재 배포 환경에는 중앙 상태 API가 연결되어 있지 않다.

### 링크

`NOWGO_PLACE_URLS`, `NOWGO_REVIEW_URLS`에는 실제 확인된 매장별 URL만 설정. 가매장·외부 호스트는 차단. 리뷰 경로나 매장 슬러그를 추측해서 만들지 않는다.
현재 main에서 확인된 점주 진입 경로는 `/owner/login`. 고객 통합가입 경로로 오인하지 않는다.

## 9. 실제 반영 범위와 남은 중앙 작업

HOT 측 구현: 빨간 로고 공통화, 8단 캠페인 카피, 지도 필터·상세, 독립 가입 API 종료, 통합 인증 시작·콜백·세션 어댑터, 통합회원 제보 제한, 의심 제보 보류, 공식 상태 출처·만료·메뉴 구분, 리뷰 미니홈피 연결 유지. 새 D1 마이그레이션은 0003이며 기존 고객 데이터는 삭제하지 않는다.

2026-09-24 확인한 NOWGO main(961eb83d8f2ed74c9b157d53f5ae722c3cca3ca8)에는 점주 소셜 로그인과 내부 콜백이 있으며, 요청한 고객 통합가입/외부 SSO 제공 경로는 확인되지 않았다. 현재 연결된 GitHub 기능은 조회용이며 중앙 운영 서버의 코드 쓰기·DB 변경·배포를 이번 작업에서 실행하지 않았다.

따라서 HOT의 통합가입 UI는 ‘연결 준비 중’으로 표시하고 새 별도 계정을 받지 않는다. 통합 로그인 전 제보 제출은 거절한다. 이 배포를 통합회원 전체 출시 완료라고 부르지 않는다.

중앙에서 필요한 작업:
1. 기존 인증과 연결되는 닉네임·번호·비밀번호 통합가입 및 복구·탈퇴·번호 인증.
2. HOT 클라이언트 등록과 승인 callback 허용, PKCE/code 교환/userinfo/권한 철회.
3. 중앙 회원 ID에 리뷰·단골·검증 기여·동의 연결.
4. HOT 제보 장소와 실제 매장·메뉴의 검증된 매핑.
5. 소유권 확인 점주의 공식 상태와 정확한 매장 리뷰 URL 제공.
6. 양쪽 연결 후 통합가입 → HOT 복귀 → 제보 → 상태 확인 → 미니홈피 리뷰를 끝까지 검증.

## 10. 출시 판정과 약관

UI 변경, 코드 저장, 비공개 시안 배포, 중앙 운영 연결 완료는 별도 상태다. 실제 중앙 연결 없이 완료 배지를 만들지 않는다. 기존 Sites 공개 범위를 유지하며 hot.nowgo.space DNS는 변경하지 않는다.

약관은 운영 검토용 초안. 허위 제보의 정정·비공개·삭제·제한과 소명 절차를 두며 모든 착오에 일률적 벌금이나 회사 책임의 부당한 전가를 하지 않는다. 중앙 가입 약관과 HOT 제보 동의의 버전을 연결해야 한다. 실제 연락처·책임자·보유기간·위탁·국외이전 안내는 중앙 운영정책 확정 후 공개한다.
